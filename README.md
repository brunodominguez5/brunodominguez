# brunodominguez
Calculadora web de diversidad de trips: Shannon, Simpson, Pielou, Bray-Curtis, dendrograma UPGMA, Mann-Whitney y ANOSIM. Cargá los conteos por lote y especie, o pegalos desde Excel, y obtené los resultados con una explicación en lenguaje simple y un análisis listo para copiar. Funciona en el navegador, sin instalar nada
